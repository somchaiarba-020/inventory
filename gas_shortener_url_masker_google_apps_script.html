ประวัติแอปที่สร้างไว้ (ในเครื่องนี้)

บันทึกอัตโนมัติในเบราว์เซอร์เพื่อเรียกคัดลอกหรือดาวน์โหลดซ้ำได้เร็ว

ยังไม่มีประวัติการสร้างลิงก์ — กรอก URL และชื่อแอปด้านบนเพื่อเริ่มต้นใช้งาน

รอรับข้อมูล URL และชื่อแอป

เมื่อกรอกข้อมูลและกดสร้าง ระบบจะแสดงผลลัพธ์ 2 รูปแบบให้เลือกใช้:

1. ลิงก์ย่อแบบใช้ได้ทันที (Dynamic)

แชร์ได้เลยโดยไม่ต้องอัปไฟล์เพิ่ม ซ่อนลิงก์ script.google.com อัตโนมัติ

2. ไฟล์ index.html เฉพาะแอป (URL สั้นที่สุด)

ดาวน์โหลดไปวางในโฟลเดอร์หรือ Repo บน GitHub Pages เพื่อได้ลิงก์สั้นแบบ username.github.io/ชื่อแอป/

สร้างสำเร็จ

แบบที่ 1: ลิงก์ย่อแบบใช้ทันที

ไม่ต้องอัปไฟล์เพิ่ม

QR Code สำหรับแชร์

สแกนเพื่อเปิดหน้าเว็บที่ซ่อนลิงก์จริงและแสดงชื่อแอปของคุณทันที

แบบที่ 2: ไฟล์ index.html เฉพาะแอป

URL สั้นที่สุด

นำไฟล์นี้ไปวางในโฟลเดอร์ย่อย (เช่น /leave/index.html) หรือ Repo แยกบน GitHub Pages เพื่อให้ได้ลิงก์สั้นแบบไม่มีรหัสต่อท้าย และเข้ารหัส URL จริงไว้ในโค้ด

สำคัญมาก — ต้องตั้งค่าใน Apps Script

อนุญาตให้ Google Apps Script แสดงผลแบบซ่อน URL

โดยค่าเริ่มต้น Google จะบล็อกไม่ให้เว็บภายนอก (เช่น GitHub Pages) ครอบหน้าเว็บแอปด้วย iframe เพื่อความปลอดภัย ให้เพิ่มคำสั่ง setXFrameOptionsMode ในฟังก์ชัน doGet() ของไฟล์ Code.gs 



          

            

              
1. Deploy เป็น Web App

              
กดปุ่ม Deploy > New deployment (หรือ Manage deployments > แก้ไขเป็นเวอร์ชันใหม่ทุกครั้งที่แก้โค้ด)

            

            

              
2. ตั้งสิทธิ์การเข้าถึง

              
เลือก Execute as: Me และ Who has access: Anyone เพื่อให้เปิดผ่านลิงก์ย่อได้ทันทีโดยไม่ติดหน้าล็อกอินซ้อน

            

            

              
3. คัดลอก URL ที่ลงท้าย /exec

              
นำลิงก์ Web App URL (ที่ลงท้ายด้วย /exec ไม่ใช่ /dev) มาวางในแท็บ สร้างลิงก์ย่อ
